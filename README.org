* kolangfine
Kiwi 형태소 분석기를 활용한 한국어 띄어쓰기 교정 도구

** 개요
국내 상장 기업 공시 등 문서에서 발생하는 잘못된 띄어쓰기를 교정합니다.
- 공백을 모두 제거한 후 Kiwi 형태소 분석을 수행하여 정확한 어절 경계를 복원
- 합성명사/고유명사(투자신탁, 집합투자기구 등) 사전 등록으로 분리 방지
- 괄호류 위치 보정 (명사 사이에 끼인 괄호를 바깥으로 이동)
- 숫자/특수문자 결합 처리 (100,000좌, 80%, 제110조 등)

** 요구사항
- Go 1.21 이상
- Kiwi 모델 파일 (=./base/= 디렉토리)

** 설치

#+begin_src shell
git clone <repository-url>
cd kolangfine
go mod download
#+end_src

** 실행

#+begin_src shell
go build -o kolangfine .
./kolangfine
#+end_src

또는 직접 실행:

#+begin_src shell
go run main.go
#+end_src

** 입출력 예시

*** 문자열 입력
| 입력 | 출력 |
|------+------|
| =다음 각 호와 관련된 법 령 및 규정이 변경되는 경우에는= | =다음 각 호와 관련된 법령 및 규정이 변경되는 경우에는= |
| =투자대상 의 규모 및 유동성 등을 고려하여= | =투자대상의 규모 및 유동성 등을 고려하여= |
| =수 익자가 당해 환매청구접수의 취소를= | =수익자가 당해 환매청구접수의 취소를= |
| =고위험자산에 8 0%이상 투자하는= | =고위험자산에 80%이상 투자하는= |

*** 배열 입력
#+begin_example
Input:  ["이", "투자신탁은", "추가", "자금납입이", "가능한", "투", "자신탁으로", ...]
Output: ["이", "투자신탁은", "추가", "자금납입이", "가능한", "투자신탁으로", ...]
#+end_example

** 주요 함수

- =correctSpacing(k, input string) (string, error)= : 문자열 띄어쓰기 교정
- =correctSpacingArray(k, input []string) ([]string, error)= : 배열 띄어쓰기 교정
